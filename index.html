1 PlayMCP란 무엇인가?

PlayMCP는 카카오가 개발한 국내 최초 MCP 기반 개방형 플랫폼입니다. 2025년 8월 베타 오픈 이후, 카카오톡, 카카오맵, 멜론, 톡캘린더 등 카카오 서비스와 약 200개 이상의 외부 MCP 서버를 한 곳에서 관리하고, ChatGPT, Claude 같은 AI 서비스에서 바로 사용할 수 있게 해줍니다.

처음 오신 분을 위한 안내: MCP가 뭔지 몰라도 괜찮습니다. PlayMCP는 "AI에게 슈퍼파워를 주는 도구 모음"이라고 생각하시면 됩니다. 예를 들어, AI에게 "오늘 일정 알려줘"라고 말하면 AI가 직접 카카오 톡캘린더에서 일정을 가져오는 것 — 이것을 가능하게 하는 게 바로 PlayMCP입니다.

2 MCP 기본 이해

MCP(Model Context Protocol)는 AI 모델이 외부 데이터나 도구와 소통하는 방식을 표준화한 통신 규약입니다. 쉽게 말해, AI가 다양한 서비스(캘린더, 지도, 메신저 등)와 대화할 수 있도록 만들어주는 "만능 어댑터"와 같습니다.

MCP가 없을 때 vs 있을 때

MCP 없이 (기존 방식) MCP 사용 시
AI에게 질문 → 직접 서비스 이동 → 결과 복사 → 다시 AI에 붙여넣기 AI에게 자연어로 요청 → AI가 MCP를 통해 직접 서비스 호출 → 결과 바로 전달
서비스마다 별도 API 연동 필요 하나의 표준 프로토콜로 통합 연결
개발자만 활용 가능 비개발자도 AI 대화로 활용 가능

MCP는 Anthropic이 2024년 11월에 오픈소스로 공개한 표준 프로토콜입니다. USB가 다양한 기기를 하나의 포트로 연결하듯, MCP는 다양한 외부 서비스를 AI와 하나의 방식으로 연결해줍니다.

초보자를 위한 쉬운 비유

스마트폰에 앱스토어에서 앱을 다운받아 설치하면 다양한 기능을 쓸 수 있죠? MCP도 비슷합니다. AI에게 "앱"을 설치해주는 것이라고 생각하면 됩니다. PlayMCP의 도구함이 바로 AI용 앱스토어 역할을 합니다.

도구함(Toolbox) 기능

도구함이란?

PlayMCP에 등록된 MCP 도구 중 내가 원하는 것만 골라 담는 개인화된 AI 도구 세트입니다. 최대 10개의 MCP 서버를 하나의 도구함에 담을 수 있으며, 이 도구함을 통째로 외부 AI 서비스(Claude, ChatGPT)에 연결하면 카카오 계정 한 번의 인증만으로 모든 도구를 사용할 수 있습니다.

👉 내 도구함 바로가기

10개 제한 주의! 도구함에는 최대 10개의 MCP 서버만 추가할 수 있습니다. 11개째를 추가하려고 하면 "적용 가능한 MCP 서버 수(10)를 초과했습니다" 라는 오류 메시지가 나타납니다. 불필요한 도구를 먼저 제거한 후 새 도구를 추가하세요.

10개 초과 시 실제 오류 화면 — "적용 가능한 MCP 서버 수(10)를 초과했습니다."

4 PlayMCP 시작하기

Step-by-Step 설정 가이드

1

PlayMCP 사이트 접속

Windows PC에서 Chrome, Edge 등 웹 브라우저를 열고 playmcp.kakao.com에 접속합니다. 별도의 프로그램 설치는 필요 없습니다. 주소창에 URL을 직접 입력하거나, 이 가이드의 링크를 클릭하세요.

2

카카오 계정으로 로그인

카카오 계정으로 로그인합니다. 최초 이용 시 본인 인증이 필요할 수 있습니다. 카카오메일 아이디, 이메일 또는 전화번호로 로그인하세요.

3

MCP 도구 탐색

홈 화면에서 다양한 MCP 도구를 탐색합니다. 각 도구 카드를 클릭하면 제작사, 제공 Tools 수, 누적 Tool Call 수 등 상세 정보를 확인할 수 있습니다.

4

도구함에 도구 추가

상단 메뉴에서 '도구함'을 클릭하고, 'MCP 추가하기' 버튼으로 원하는 도구를 자유롭게 추가합니다. 최대 10개의 MCP 서버를 담을 수 있습니다.

5

AI 서비스에 연결

도구함 설정이 완료되면, Claude 또는 ChatGPT에서 PlayMCP 도구함을 연결합니다. (상세 방법은 아래 섹션 참고)

개발자 콘솔에서 직접 MCP 서버를 등록할 수 있습니다. 등록 과정은 3단계로 진행됩니다:

단계내용

Step 2도구(Tool) 목록 확인 및 설정

향후 카카오 시너지를 통해 더 많은 개발자 지원 기능이 추가될 예정입니다.

이용가이드를 꼭 확인하세요! PlayMCP의 이용가이드 페이지에서 도구함 연결 방법, Claude 연결 방법, ChatGPT 연결 방법을 스크린샷과 함께 상세히 안내하고 있습니다.

현재 베타(Beta) 서비스입니다. 일부 기능이 제한되거나 변경될 수 있으며, remote MCP 서버만 등록 가능합니다.

5 Claude에서 PlayMCP 연결하기

Claude에서 PlayMCP를 연결하는 방법은 두 가지입니다. 처음이시라면 방법 1(커넥터 디렉터리)을 추천합니다 — 클릭 몇 번이면 끝납니다.

연결하기 전 체크리스트 (Windows 사용자):
(1) Windows PC에서 Chrome 또는 Edge 브라우저로 claude.ai에 접속 → 계정 로그인
(2) 다른 탭에서 PlayMCP 도구함을 미리 구성해두세요 — 도구함이 비어있으면 연결해도 쓸 수 있는 도구가 없습니다
(3) Claude Pro 또는 Team 플랜에서 커넥터 기능을 사용할 수 있습니다

방법 1: Claude 커넥터 디렉터리에서 연결 (추천)

1

Claude 디렉터리 접속

Claude 설정 → 커넥터 → 디렉터리에서 "PlayMCP"를 검색하거나, 아래 URL로 직접 접속합니다.
claude.ai/settings/integrations → "PlayMCP" 검색

2

'연결' 버튼 클릭

6 ChatGPT에서 PlayMCP 연결하기

ChatGPT에서 PlayMCP를 연결하는 방법은 두 가지입니다. ChatGPT Plus/Pro 사용자라면 아래 방법으로 연결할 수 있습니다.

방법 1: ChatGPT 설정 > 앱에서 연결 (추천)

1

ChatGPT 설정 열기

Windows PC에서 Chrome 또는 Edge 브라우저로 chatgpt.com에 접속합니다. 로그인 후, 좌측 하단의 프로필 아이콘 → '설정'을 클릭합니다.

2

'앱' 메뉴에서 PlayMCP 찾기

설정 메뉴에서 '앱' 탭을 클릭합니다. 앱 목록에서 "PlayMCP"를 검색하거나 스크롤하여 찾습니다. PlayMCP 옆의 '연결' 버튼을 클릭합니다.

3

카카오 계정으로 OAuth 인증

PlayMCP 연결 화면이 나타나면 '연결' 버튼을 클릭합니다. 카카오 계정 로그인 화면이 표시되며, 로그인 후 '동의하고 계속하기'를 클릭하면 연결이 완료됩니다.

4

연결 완료 확인

설정 → 앱 목록에서 PlayMCP 상태가 '연결됨'으로 변경된 것을 확인합니다. 이제 ChatGPT 채팅에서 도구함에 담긴 모든 MCP 도구를 사용할 수 있습니다.

chatgpt.com/settings/apps

방법 2: 개발자 모드로 MCP 서버 직접 등록

ChatGPT에서 '개발자 모드'를 선택한 후, 맞춤형 MCP 서버 설정에 아래 URL을 등록합니다.

https://playmcp.kakao.com/mcp

개발자 모드는 ChatGPT Plus/Pro 사용자가 고급 설정에서 활성화할 수 있습니다.

Claude vs ChatGPT 연결 차이: Claude는 '커넥터' 메뉴에서, ChatGPT는 '앱' 메뉴에서 연결합니다. 둘 다 같은 MCP 서버 URL(https://playmcp.kakao.com/mcp)을 사용하며, 한 번 연결하면 도구함에 담긴 모든 도구를 동일하게 사용할 수 있습니다.

ChatGPT에 PlayMCP 연결하기 — 개인정보 제3자 제공/국외 이전 동의 후 "모두 동의 후 계속하기" 클릭
ChatGPT 설정 > 앱 메뉴 — "더 추가하기" 버튼으로 PlayMCP를 포함한 다양한 앱을 연결할 수 있습니다

10 FAQ & 트러블슈팅

Q. PlayMCP는 무료인가요?

네, 현재 베타 서비스로 무료로 사용할 수 있습니다. 카카오 계정만 있으면 됩니다.

Q. 개발자가 아니어도 사용할 수 있나요?

네, 도구함에 원하는 도구를 담고 AI 서비스에 연결하는 것까지 코딩 없이 가능합니다. 비개발자도 쉽게 사용할 수 있도록 설계되었습니다.

Q. 어떤 AI 서비스에서 사용할 수 있나요?

현재 Claude, ChatGPT, 오픈클로(OpenClaw) 등에서 사용 가능합니다. 향후 더 많은 AI 서비스가 지원될 예정입니다.

Q. 내 개인 데이터는 안전한가요?

PlayMCP는 카카오 계정 기반의 OAuth 인증을 사용하며, 사용자가 허용한 범위 내에서만 데이터에 접근합니다. 카카오의 개인정보처리방침이 적용됩니다.

Q. 연결이 안 될 때는 어떻게 하나요?

PlayMCP 이용가이드에서 상세 안내를 확인하거나, 디스코드 채팅 상담을 이용하세요. Claude의 경우 Pro/Team 플랜이 필요하며, ChatGPT는 Plus/Pro 플랜이 필요합니다.

Q. "MCP 서버 수(10)를 초과했습니다" 오류가 나타납니다.

도구함에는 최대 10개의 MCP 서버만 추가할 수 있습니다. 사용하지 않는 도구를 도구함에서 제거한 후 새 도구를 추가하세요.

⚠

적용 가능한 MCP 서버 수(10)를 초과했습니다.

실제 오류 메시지 재현

Q. Claude와 ChatGPT 중 어디에 연결하는 게 좋나요?

둘 다 같은 MCP 서버를 사용하므로 기능 차이는 없습니다. 평소 주로 사용하는 AI 서비스에 연결하세요. 두 곳 모두에 동시에 연결하는 것도 가능합니다.

Q. 도구함 URL은 어디서 확인하나요?

도구함 페이지 하단의 '연결하기' 영역에서 MCP 서버 URL을 확인하고 복사할 수 있습니다. URL은 https://playmcp.kakao.com/mcp 입니다.

Q. 나만의 MCP 도구를 만들어 등록할 수 있나요?

네, 개발자 콘솔에서 직접 MCP 서버를 등록할 수 있습니다. 현재는 remote MCP 서버만 등록 가능합니다.
